# アリの行列シミュレーター

子供の頃に庭先でアリの行列へ小石や葉っぱを置いてしまうような、無邪気な干渉をテーマにした 2D ブラウザゲームです。見た目はくすみ系で、アリの不快感や競技性よりも、行列が崩れて立て直される動きの観察を重視しています。

## 遊び方

- 小石、葉っぱ、指跡、水滴、水ポンプを選んで地面へ置きます。置いたものをもう一度クリック/タップすると取り除けます。
- 水ポンプは近くのアリを派手に流し、短時間だけ行列を大きく乱します。
- 謎は毎回違うおじゃまを発動し、水しぶきや葉っぱなどの効果がランダムに起きます。
- 生態ノートから、フェロモン、経路記憶、ゲーム内モデルの根拠を読めます。
- 倍速ボタンで、1倍速 / 3倍速 / 5倍速 / 10倍速 / 20倍速を切り替えて高速観察できます。
- ときどき大きいかけらを運ぶアリが現れます。
- スコアやお題はなく、アリが運んだカケラの総数だけを表示します。
- 開始時やリセット時は、10種類の初期パターンから巣と餌の位置が選ばれます。餌は基本1か所で、まれに2か所になります。
- 庭の分かれ道、渋谷スクランブル交差点をモチーフにした渋谷交差点、山と小川の 3 マップを切り替えられます。
- アリは巣と食べ物の間を行き来しながらフェロモンを残します。
- 妨害で行列が乱れると、アリは探索しながら新しい流れを作り直します。

## 研究ベースの簡略モデル

- フェロモン濃度差に応じて旋回する Weber 型ルール: Perna et al., 2012
- ランダム探索、フェロモン追従、蒸発、拡散: Malíčková et al., 2015
- 複雑経路でのフェロモンと経路記憶: Czaczkes et al., 2013
- 過剰な匂いによる行列の一時的な乱れ: Suckling et al., 2008

厳密な生物シミュレーションではなく、論文由来の行動ルールをゲーム向けに抽象化しています。
詳しい再調査結果と実装上の扱いは [docs/ant-behavior-model.md](docs/ant-behavior-model.md) にまとめています。
